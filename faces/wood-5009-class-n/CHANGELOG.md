# Wood 5009 Class N — changelog

Revival of Barnhart Bros. & Spindler wood type **No. 5009, Class N** (a heavy
Egyptian slab), from *Book of Type Specimens, Specimen Book No. 9* (Chicago,
1907), leaf 893 / printed page 849 — archive.org `bookoftypespecim00barnrich`,
400 ppi, public domain.

Maturity: **proto** (0.x, traced, machine-spaced) → **draft** → **release**.

## 0.1.0 — 2026-08-30 · proto

- Everything the page shows, traced with potrace from five sizes: "HIRE" (ten-line),
  "BONES" (eight), "CORNS 8" (six), "GROUNDS" (five), "Modernized 5" (four).
  Capitals B C D E G H I M N O R S U; lowercase d e i n o r z; figures 5 8;
  same-letter alternates from other sizes kept unencoded.
- Glyphs from each line share its baseline and scale; lowercase lands at an
  x-height of 524 units, figures at cap height.
- Spacing derived from the printed gaps (half the median: 27 units a side).
- No constructed letters yet; no kerning.
